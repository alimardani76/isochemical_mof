# Input-data manifest

Raw ARC–MOF inputs are not redistributed in this repository.

The analysis used **ARC–MOF release v7, Zenodo record 16802743**. This directory records required upstream filenames, source inventory/hashes captured during the frozen analysis, and files omitted from ordinary Git hosting because of size.

`REPO_FILE_MANIFEST.csv` is a provenance snapshot from the frozen analysis/handover stage. It should not be interpreted as a dynamically regenerated listing of every later publication-documentation file.

For current publication-artifact hashes, see `../PUBLICATION_ARTIFACTS.md`.
