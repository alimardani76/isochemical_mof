# Raw Data Required

Project 17 uses ARC-MOF release v7, Zenodo record 16802743.

Raw ARC-MOF source data are intentionally not redistributed in this repository.

To reproduce the full workflow, reconstruct the local raw/ directory using
the source files listed in:

data_manifest/RAW_DATA_INVENTORY.csv

The inventory records the expected filenames, sizes, and SHA256 checksums.

Do not substitute a different ARC-MOF release without treating it as a new
analysis version.
