# Generated-artwork status

This directory is reserved for generated publication artwork.

The previously committed pre-redesign figure binaries have been moved to `../archive/legacy_pre_redesign/` so that they cannot be mistaken for the current submission figures.

For current quantitative figures, use the reproducible generators under `../redesign/`. Exact current submission-artifact hashes are recorded in `../../PUBLICATION_ARTIFACTS.md`.

Figure 5 has a separate rendering/composite workflow under `../source/` and `../../submission_upgrade/`.

Generated binaries should be attached to the permanent release/archive rather than treated as the scientific source of truth.
